# SPOS
This is first my webOS. I have made a batman-themed webOS for the same. I have added usefull things like weather, calculator, notes and todo app to it and some fun things like batcave(an app which shows you the most legendary batman quote of all time). I also made a startup screen for it which the legendary bat signal. You can feel free to check it out as many times as you want.
